# crema. — сайт кофейни (концепт для портфолио)

**Живой сайт:** https://starsipo.github.io/crema/

Одностраничный сайт вымышленной городской кофейни **crema.**: specialty-кофе,
свежая выпечка, спокойная атмосфера. Кофейня, адрес и цены вымышлены.

Чистые HTML, CSS и JavaScript: без сборки и без зависимостей. Шрифты и фото
лежат локально.

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

Для публикации подойдёт любой статический хостинг: GitHub Pages, Netlify и т. п.
Сайт публикуется на GitHub Pages автоматически при каждом пуше в `main`
(`.github/workflows/pages.yml`).

## Структура

```
./
├── index.html        — разметка всех разделов
├── credits.html      — источники фото и шрифтов
├── css/style.css     — дизайн-токены, сетка, адаптив, анимации
├── js/main.js        — мобильное меню, вкладки меню, якоря, статус «открыто», появление
└── assets/
    ├── img/          — фото Unsplash (WebP, по два размера для srcset)
    └── fonts/        — Cormorant Garamond + Manrope (SIL OFL), кириллица и латиница
```

## Что внутри

- Палитра: молочный `#F4EFE6`, кофейный `#2A1D15`, оливковый `#5D6741`
  (контраст текста не ниже 5.6:1).
- Типографика: Cormorant Garamond для заголовков, Manrope для текста.
- Вкладки меню — доступные ARIA-табы (стрелки, Home/End). Без JS все три
  категории показываются списком.
- Мобильное меню: Esc закрывает, фокус остаётся внутри, прокрутка страницы
  блокируется.
- Статус «открыто / закрыто» считается по часовому поясу Europe/Chisinau.
- Учитывается `prefers-reduced-motion`: при этой настройке анимации и плавная
  прокрутка отключаются.
- Адаптивность от 360 px; изображения грузятся лениво, через `srcset`.
